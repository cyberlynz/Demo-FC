# Demo FC Hub

Football tournament management application built with TanStack Start, React, TypeScript, Tailwind CSS, and Supabase.

## Local development

1. Install Node.js LTS.
2. Copy `.env.example` to `.env` and fill in the required Supabase project values.
3. Install dependencies with `npm install`.
4. Start the local preview with `npm run dev`.
5. Open the local URL printed by Vite in your browser.

## Available commands

- `npm run dev` — start the local development server
- `npm run build` — build the app
- `npm run lint` — run ESLint
- `npm test` — run the test suite

## Security

- Real `.env` files are excluded from Git.
- Never commit service-role keys, private tokens, or real player/payment data.
- Configure Supabase credentials locally before testing database-backed features.
